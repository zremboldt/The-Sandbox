# Pricing Card Exercise

Welcome!
Your task is to build a small set of pricing cards in React based on the provided Figma design. Focus on clear component structure, thoughtful CSS, and a responsive layout.

You are not expected to finish the full design — we’re more interested in your approach, communication, and reasoning than pixel-perfect completion.

⸻

## Todos

• Build a reusable PriceCard component.
• Render multiple cards using the provided data.
• Create a layout that adapts smoothly from desktop to mobile.
• Use semantic HTML and accessible patterns where appropriate.
• Style the page to match the Figma design.
